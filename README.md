# Project Title
Alpuerto's Portfolio

## Overview
A personal portfolio website built with HTML, CSS, JS, and semantics featuring an introduction section, about section, services section and a working contact me section.

## Features
- Navigation menu toggle and dark/light mode theme switcher on top.
- Services table arranged rendered from JavaScript array of objects.
- Contact form validation error messages.
- Visitor settings saved as JSON object stored under 'app_settings'.

## Technologies
- HTML5
- CSS3
- JavaScript
- Git and InfinityFree

## Setup
1. Open project folder in VS Code.
2. Confirm 'index.html', 'css/styles.css', js/script,js', assets in 'assets/', fallback screenshot in 'screenshots/'.
3. Open 'index.html' in a browser or local server to test controls.
